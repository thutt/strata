WHAT IS NOT IMPLEMENTED YET: A REPORT BY MENU
=============================================

Written 2026-11-13 from the menu tables in src/ui.c and src/str.c, the
panels in src/globalmenu.c, src/printmenu.c and src/filemenu.c, and the
documents in docs/ (WORKLIST.txt, KEYSTROKES.txt, GLOBAL-MENU.txt,
TOOLS-MENU.txt, PRINT-MENU.txt, MARKERS.txt).  Each item says how it shows
to the user: DIMMED (the entry is shown and cannot be chosen), NOTICE (the
entry can be chosen and says it is not implemented), SHOWN (the panel field
is shown and ignored), MESSAGE (the key only prints a message) or SILENT
(nothing in the menus says so).  "Running" means a task is working on it.

Corrected 2026-11-25: the entries for Edit Window, Tools Spell, Tools
Thesaurus and "Running now", and the paper sizes of Global Page, were out of
date and are corrected.  The other entries are as they were on 2026-11-13 and
have not been checked again.


1. SUMMARY
----------

  stred menu bar     Everything can be chosen (Edit Window, Tools Spell and
                    Tools Thesaurus work: they were dimmed on 2026-11-13).
                    Print Repaginate and Print Clear-pages are not in the
                    menu (removed 2026-11-18: the page breaks are made when
                    a document is printed).
  str menu           Every entry works (Maintain Dictionaries and Compare
                    Document Versions were the two that gave a notice).
  Panel fields      Shown and ignored: most of str Setup, six settings of
                    stred Global Options, and several Global Format and Page
                    fields.
  Keys              See section 4.
  Markers           Five are removed on purpose.  The others are stored and
                    edited; about half have no effect yet when a page is
                    made (section 5).

  Running now:      nothing that this report knows of.
  Wrong, to fix:    nothing is known to be wrong in the Preview entries.


2. stred: THE F12 MENU BAR
--------------------------

File.  All six commands work (Save, Retrieve, New, Delete, Import, Export).
  Import and Export have UTF-8 and Latin-1 in the Character Set choices
  (UTF-8 stage 0).  Documents are still CP437: a character with no place
  in CP437 (a Chinese character, an emoji) is a ? after Import and is
  counted in the message line, and nothing but the keyboard of the Editor
  takes it.  UTF-8 in the document itself is the later stages of
  docs/UTF8.txt.
  Left: Retrieve Named Block Settings Only (what it replaces is not known),
  refusing Ctrl-S on a .BAK file, borders in an exported screen image.

Global.  All six commands open panels.  Not done inside them:
  - Format: Spacing for Bottom Alignment of the Winding Column Layout panel.
  - Format: nothing is stored and unused now.  The
    spacings (also those that a block or its named format sets), Page Break
    Level, Auto Numbering to Level and the fonts are used.
  - Page: the paper sizes and margins are used by Print and Preview
    (docs/PRINT-LATEX.txt).  The Header and Footer fields ("...")
    do not open the editor of the original: headers and footers cannot be
    edited (SILENT).
  - Options: six of thirteen settings are dimmed: Block Indicators (Solid
    Lines), Display Even Justification, Display +/- with Section Tags,
    Units, Autosave and Save Interval (the same truth is in str Setup), and
    Line Weight (Borders and Other) (DIMMED).
  - Marker: the Footnote, Levelnote, Endnote, Counter and Keycap Formats are
    done.  Marker display modes are done.
  - Named: Edit and Delete work.

Edit.  Title, Structured, Unstructured, Section and Document work.
  - Window (Open, Close, Adjust, Zoom-up, Zoom-down, Switch): WORKS (the
    manual, Edit, Window).  Ctrl-W (switch windows) is "no" in KEYSTROKES.txt.

Print.
  - Draft and Final: DONE.  They make a PDF with strprint and send it to a
    CUPS queue with lp (docs/PRINT-MENU.txt); "stred --print" does the same
    from a shell.  The sending to a real CUPS queue was not tried (the tests
    use a stand-in for lp).  The table of contents is DONE (the Print panel
    fields Table of Contents? and Contents Levels, docs/PRINT-LATEX.txt).
    Not done: the other parts of the original's check list (figures,
    tables, the index, the print summary), Print Quality (no CUPS
    setting is mapped to it), the graphics options, headers and footers
    other than the page number (PRINT-LATEX.txt, 14).
  - Preview (Document, Block, Section): works through LaTeX and dviview.
    Not driven by a test in the X11 stred.
  - Error Log, Print Errors and the failed-print banner: DONE (docs/
    PRINT-LATEX.txt, 17 and 17.8; docs/MARKERS.txt, "Print Error").  Not
    done: the Error Log Markers (an E at
    the end of each line with an error), the error count in a Document Print
    Summary (there is no summary), a list of the errors in a window, a
    Preview that does not block the Editor, and a click in the Viewer that
    goes to the error.  Undo takes the inserted markers out as one
    operation, as Remove Print Errors does.  The Error Log
    lists what the writer and LaTeX found: a defect that neither can see
    (a wrong word, a bad layout) is not an error.
  - Repaginate and Clear-pages: REMOVED from the Print menu (owner,
    2026-11-18).  They were dimmed.  They depend on the typographic
    formatter of the original, which Strata does not have, so page breaks
    are known only at print time.  Ctrl-PgUp and Ctrl-PgDn (previous and next
    page) need pages too and are "no".
  - Not done anywhere: lists of figures and tables, the index (the Index,
    Figure and Table markers are stored and ignored).  The table of
    contents of a print is made from the headlines and is asked for in the
    Print panel, not by a marker.

Tools.
  - Macros, Library, Autosort and Count work.
  - Spell (Document, Block, Section, Word) and Thesaurus: WORK.  Ctrl-C spell
    checks the current word and Ctrl-T looks it up in the thesaurus.

Quit.  Works.  (The Shell entry was removed on purpose: the system is
multitasking.)

5. MARKERS (docs/MARKERS.txt)
-----------------------------

Removed on purpose: Worksheet, Markup, Escape Codes, Symbol, Screen.

All the others can be inserted, edited and saved.  Their effect when a page
is made (strprint, Preview) is done for: Keycap, Picture, Equation, Page
Break, Column Break, Orientation, Whitespace, Font, Cross-reference, Counter,
Keep and the notes.  Keep is never printed and keeps the blocks between a
Start and an End on one page (PRINT-LATEX.txt, MARKERS.txt); what the
original does and Strata does not copy: a part with a Page Break, Column
Break or Orientation marker, or in the text of the title page, is not
kept; whether a Start without an End stops at the end of a section is not
known (Strata keeps to the end of the document); the Table of Contents,
the Index and Repaginate do not use Keep.  It is still to be written, or to
be checked, for:

  Line, Merge, If, Else, Endif, Figure, Table, Index,
  Page Number and Section (headers and footers cannot be edited), Printer,
  and the values Date, Time, Filedate, Filetime, Filename, Pathname,
  Revision, Author and Description in printed output.

Merge and If/Else/Endif: what the original's expression language and merge
files are is not known (OPEN-QUESTIONS.txt).


6. OTHER GAPS
-------------

  Not menu entries, but visible to the user:
  - Search panel: direction, match case, attribute and whole word options.
  - Colour: the screen has configurable colours (Setup, Screen Colors); the
    default is yellow on blue.  The original colours of headlines and
    borders are not drawn as such.
  - Borders: the Line Weight (Borders) of Global Options is dimmed and not
    used; the lines have a fixed weight (a thin line, two thin lines, a thick
    line).  The screen draws wide as bold double.
  - Hyphenation settings of the print panels (R3 of docs/DICTIONARIES.txt, later).
    The soft hyphen and the personal hyphenation list are done (task 35).
  - A text file save mode (the .DOC format is binary).
  - A safe save: write to a temporary file, then rename; Autosave saves
    under the name of the document.
  - Mouse (studied in docs/MOUSE.txt; neither version takes mouse input).
    The X11 window can be resized in height (the width is fixed).
  - Guarding the PNG reader against hostile images (limits on pixels and
    inflated size, tests under the address sanitizer).
  - The Picture panel reported not to take input in some fields was fixed;
    the smoke test that types into every field of the marker panels is
    still to be written.
