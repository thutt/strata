# The symbols of the Math Symbols card.  This list is the one place that
# holds them: manual/mkmathcheat.py makes the source of the card
# (manual/src/mathcheat.src) from it, and manual/checkmathsyms.py checks it.
#
# A line that begins with a number sign is a comment.  The other lines are:
#
#   @panel N         The groups that follow are on panel N of the six panels
#                    (1 to 3 on the outside of the sheet, 4 to 6 inside).
#   @group TITLE     A group: a heading, and the entries up to the next
#                    @group or @panel.
#   @again           The group repeats entries that are listed elsewhere (the
#                    most used symbols): they are not counted twice.
#   TEX TEX ...      Entries that are small: each word is the text of an
#                    equation, and it is also the text to type.  A word
#                    @bar stands for a plain vertical bar.
#   (a space)        A line that begins with a space goes on from the line
#                    before it (so that no line is longer than 80 columns).
#   > TEX | NOTE     An entry that has a line of its own: the text of the
#   > TEX | TYPED | NOTE
#                    equation, the text to type when it is not the same
#                    (a shorter form of a long text), and a short note.
#
# Every entry is typeset by the Printer in an equation, and the check fails
# when the Printer reports a fault.  The names that the packages define and
# that are not here are in manual/mathsyms-left-out.txt with the reason.
