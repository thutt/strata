KEY MAP OF THE PROGRAMS, AND THE F12 MENU ROUTES
===============================================

Made by tests/keymap.py from the source (src/ui.c, src/term.c, src/term_x11.c,
src/menu.c, src/widgets.c, src/str.c, src/macro.c, tools/dviview) and from the
menu tree that the Editor prints with --dump-menus.  It is a study: nothing in
the programs was changed.  Where a key is lost in a terminal or a desktop, the
study of docs/KEYS-ENVIRONMENTS.txt and docs/TERMINALS.txt is the source.

Mode: B both kinds of document, S structured only.  Bytes: what a terminal
sends (ESC is the byte 1B).  A key written with a comma has the same bytes as
the one before it, or is one more way to type the same command.

1.1  Function keys (the table fkeys[] of src/ui.c)

1.4  Alt keys (the Alt switch, and the macros)
----------------------------------------------------

  An Alt-letter that a macro is recorded on runs the macro and comes first: a
  macro on Alt-I or Alt-O hides the command.  Alt-1 to Alt-9 and Alt-0 work in
  a structured document.

  Key                  Command                           M   Bytes
  -------------------- --------------------------------- -   -------------------
  Alt-*                Outline the section's text        S   ESC *
  Alt-+, Alt-=         Expand the section                S   ESC +
  Alt--                Collapse the section              S   ESC -
  Alt-/                Redo                              B   ESC /
  Alt-[, Alt-<, Alt-,  Promote the section               S   ESC [
  Alt-], Alt->, Alt-.  Demote the section                S   ESC ]
  Alt-_                Soft hyphen                       B   ESC _
  Alt-I                Italics on and off                B   ESC i
  Alt-O                Overtype on and off               B   ESC o
  Alt-1 .. Alt-9       Show headlines to that level      S   ESC 1 .. ESC 9
  Alt-0                Outline the whole document        S   ESC 0
  Alt-Backspace        Delete the previous word          B   ESC 7F

1.5  Other keys
----------------------------------------------------

  Key                  Command                           M   Bytes
  -------------------- --------------------------------- -   -------------------
  Ins                  Append a section, same level      B   ESC[2~
  Shift-Ins            Append a subsection               B   ESC[2;2~
  Del                  Delete the character              B   ESC[3~

  Ctrl-Shift-Space     No-break space                    B   ESC[32;6u or 00

  While a highlight is on: Enter accepts it, Esc cancels it, the cursor keys
  move the end of it, F1 is Help, and nothing else acts.  In Autosort Home and
  End go to the edges of the section and + and - choose the direction.
  Ctrl-F1 ends a recording (Learn).  In X11 the keypad + - * are Alt-+, Alt--
  and Alt-*; in a terminal they arrive as the plain characters.

1.7  Free keys
----------------------------------------------------

  Keys that no command uses and that a terminal sends unchanged (a desktop may
  still keep some of them).

  Control: no letter is free; Ctrl-A to Ctrl-Z are all used, and Ctrl-I,
  Ctrl-J, Ctrl-M and Ctrl-H are the bytes of Tab, Enter and Backspace.  Free
  bytes: 1C (Ctrl-\), 1D (Ctrl-]).  In a terminal Ctrl-\ (1C) and Ctrl-] (1D)
  arrive unchanged; with a German or French layout Ctrl-] needs the AltGr key.

  Alt, letters: Alt-I and Alt-O are commands; every other letter, A to Z (24
  keys), is free and is the key of a macro (Macro Key: Alt-).  A terminal
  sends Alt-Shift-letter as ESC and the capital, which the macro list takes as
  the same key.

  Alt, punctuation that no command uses: ! " # $ % & ' ( ) : ; ? @ \ ^ ` { | }
  ~.  Alt-] and Alt-\ arrive plain.  Alt-[ (a command) and Alt-Shift-O cannot
  work in a terminal (section 1.8).

  Function keys: F10, F11 (no command; a macro records them), Alt-F1, Alt-F10,
  Alt-F11 (say "not available"); Shift-F1 to Shift-F11 (nothing); Ctrl-Alt
  with anything (read as Ctrl-Alt and ignored).

1.8  Keys with problems
----------------------------------------------------

  Inside the product
  - Ctrl-/, Ctrl-_ and Ctrl-Hyphen are all the byte 1F: Undo.  The soft hyphen
    was on Ctrl-Hyphen and moved to Alt-_.
  - Ctrl-I is Tab, Ctrl-J and Ctrl-M are Enter, Ctrl-[ is Esc (byte 1B): the
    same bytes as those keys.
  - Ctrl-H is Hanging indent, and Backspace is the byte 7F.  A terminal that
    sends 08 for Backspace (an xterm with backarrowKey off, a Windows console)
    makes Backspace run Hanging indent.
  - Undo has three keys (Ctrl-/, Ctrl-Z, Ctrl-F10) and Redo two (Alt-/,
    Ctrl-F11).
  - Ctrl-Space is the byte 00, which is read as the no-break space: a terminal
    cannot tell Ctrl-Shift-Space from it.
  - Ctrl-Shift with a letter is the byte of Ctrl with the letter: a terminal
    cannot send it, and the Editor has no command on it.  Ctrl-Alt-letter
    arrives as a Ctrl-Alt key and is ignored.
  - Alt-[ (promote the section) is ESC [, the start of every control sequence:
    the reader waits for the rest, times out and returns Esc.  Alt-< and Alt-,
    do the same command and work.  Alt-Shift-O is ESC O, which the reader
    takes for the start of F1 to F4 and drops.
  - An Alt-letter is ESC and the letter, within 40 ms: over a slow ssh link it
    may arrive as Esc and a letter.

  Terminals and desktops (docs/KEYS-ENVIRONMENTS.txt)
  - xterm sends Alt with a character as a character with the eighth bit set
    unless XTerm*metaSendsEscape is true: every Alt key then types a
    character.
  - Shift-Ins (Append a subsection) is the terminals' paste (xterm,
    xfce4-terminal); Shift-PgUp and Shift-PgDn are scrollback; xfce4-terminal
    also keeps Shift-Up, Shift-Down, Shift-Home and Shift-End.
  - F1 (Help) is the help of xfce4-terminal; F10 and F11 (menu, full screen)
    are taken by xfce4-terminal, GNOME Terminal and Konsole in part, and the
    two keys have no command.
  - Alt-F4 (Delete) closes the window in almost every window manager; GNOME
    takes Alt-F1, F2, F4, F5, F6, F7, F8 and F10; Xfce takes Alt-F4, F6 to F11
    and all of Ctrl-F1 to Ctrl-F12; KDE takes Alt-F2, F3, F4 and Ctrl-F1 to
    Ctrl-F4.  So Border (Alt-F8), Go To (Alt-F7), Math (Ctrl-F2), Case
    (Ctrl-F6) and the library keys are lost in some desktops; the Ctrl-F list
    reaches them.
  - tmux keeps Ctrl-B (Bold) as its prefix.
  - Konsole sends Shift-, Ctrl- and Alt-F1 to F4 as ESC O m P; the reader
    reads them since the last change.
  - Consoles without Ctrl-F and Alt-F keys (linux, screen, rxvt, vt100): those
    commands need the Ctrl-F list.

1.9  The soft hyphen and the collapse of a section
----------------------------------------------------

  Today: the soft hyphen is Alt-_ (ESC _; Alt-Shift-minus on a US layout).  A
  section collapses with Alt-- (ESC -; the keypad minus in X11), expands with
  Alt-+ or Alt-= or the keypad +, and the outline of its text is Alt-*.  Alt-
  minus was the soft hyphen key for a short time and was given up because it
  collapses a section.

  Four ways to choose.  None is chosen; the owner chooses after reading the
  whole map.

  A.  No change.  Soft hyphen Alt-_, collapse Alt--.
     Nothing moves.  The soft hyphen needs Shift on every layout, and on a
     layout where _ is not Shift-minus (French) the key is not Alt-Shift-
     minus.

  B.  Swap them.  Soft hyphen Alt--, collapse Alt-_.
     The soft hyphen is the plain hyphen key with Alt, as the old program had
     it on Ctrl-Hyphen.  Collapse takes the shifted key; the keypad minus must
     be mapped to Alt-_ in X11 or it would insert a soft hyphen; the manual
     and the cheat sheet change in four places.

  C.  Soft hyphen on Ctrl-] (the byte 1D, free).
     No Shift and no Alt: it arrives unchanged in every terminal and in X11.
     With a German or French layout Ctrl-] needs AltGr.  Alt-_ and Alt-- stay
     as they are.  A new byte for the macro recorder.

  D.  Soft hyphen only in the Ctrl-F list, and a key later.
     Nothing collides; a soft hyphen takes three keystrokes (Ctrl-F, a choice,
     Enter) and a macro can take any Alt-letter for it.  The key can be chosen
     after the whole map is read.

PART 2.  THE DOCUMENT MANAGER
=============================

  The Document Manager (src/str.c) shows menus and forms; it has no document
  keys.  The keys of its menu and form widgets are those of PART 3, with these
  differences:

  Up, Down, Home, End    move the highlight of the menu; the first letter of an
                         entry jumps to it
  Enter, Ins             choose the entry of the menu
  Esc                    leave a menu that allows it
  F1                     Help for the entry or the field
  Tab, Down, Enter       next field; Enter on the last field accepts the form
  Shift-Tab, Up          previous field (the value is checked first)
  PgUp, PgDn             next, previous page of a form with pages (Setup)
  Ins                    accept the form
  Esc                    cancel the form
  Left, Right            in a choice: the previous, next choice (no wrap); in a
                         text field: the cursor
  Space                  in a choice: the next choice (wraps)
  F2, +, Alt-+           in a choice or a name field: the list
  Home, End              in a text field: the start, the end
  Backspace, Del         in a text field: delete; Del in a Setup field puts the
                         default back
  Tab (two part field)   to the second part of the field

  In the Setup form (the Screen Colors page) Space, Left, Right and F2 choose
  a colour, Tab switches foreground and background, Del and R put a colour
  back.

The proposals, with the reason:

  Help (F1): the bar, between Tools and Quit, Help.  F1 is taken by
  xfce4-terminal; a bar entry is where a user looks for Help (letter H is free
  in the bar).

  Search (F9): Tools, before Border, Search.  There is no Search menu; the
  Edit menu is for the kind of document, so Tools holds the three search
  commands.

  Math (Ctrl-F2): Tools, before Autosort, Math.  Next to Autosort, which also
  works on a column or table.

  Lib Copy (Ctrl-F3): Tools, Library, first entry, Copy.  The library chapter
  keeps the three commands together; Library now has Edit, Delete, Save and
  Retrieve.

  Lib Cut (Ctrl-F4): Tools, Library, second entry, Cut.  As Lib Copy.

  Lib Paste (Ctrl-F5): Tools, Library, third entry, Paste.  As Lib Copy.

  Case (Ctrl-F6): Tools, before Autosort, Case.  As Border: a command on
  highlighted text.

  Search Again (Ctrl-F9): Tools, after Replace, Search Again.  As Search.

  Marker (Ctrl-F12): Edit, last entry, Marker.  Global, Marker is the marker
  SETTINGS, so inserting a marker needs a different label.

  Border (Alt-F8): Tools, before Autosort, Border.  Chapter 3 of the manual
  puts Border, Case and Math side by side, ahead of Tools: Macros and Library.

  Replace (Alt-F9): Tools, after Search, Replace.  As Search.

  The editing commands (Split, Copy, Cut, Paste, Move, Format, Table, Append,
  Join, Delete, Overtype, Set Attribute, Go To and Marker): fourteen entries
  would double the Edit menu, which the original keeps to three.  Two ways,
  and the owner chooses.  Way 1: new entries on the Edit menu with those
  names, each running the command as its key does.  Way 2: ONE new entry,
  "Commands", on the Tools menu (or on the bar), that opens the same list as
  Ctrl-F with every command that has a function key and its key (W29.1 made
  that list).  Way 2 also covers Border, Case, Math, the library commands, the
  search commands and Help, so the proposals above are the alternative to it
  for those commands.

  Letters of the bar entries: with Case, Math and Count, Macros and Math,
  Spell and Search all in Tools, a letter jumps to the first entry that starts
  with it, so a new entry changes which entry a letter reaches; the manual and
  the cheat sheet name the letters.
