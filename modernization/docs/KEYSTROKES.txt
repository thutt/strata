KEYSTROKES: STRUCTURED AND UNSTRUCTURED EDIT, AND THE EQUATION MARKER
====================================================================

Sources.  Orig: H = documented in the original's help (Keyboard Summary and
the per-command pages, extracted with tools/hlp.py); V = tried in the
original (Manuscript 2.1 under DOSBox-X) for this report; - = not in the
original.  Strata: yes = works as in the original; alt:KEY = works on
another key; diff = works differently (see the note); no = not implemented;
msg = the key only shows a message.  Mode: S = structured only, U =
unstructured only, B = both.  Control keys are the PC keys; a terminal
keeps some of them for itself, which is why Strata has alternates.

The menu key.  The original opens the menu with F10 and the Marker Commands
with Alt-F10.  Strata opens the menu with F12 and the Marker Commands with
Alt-F12 or Ctrl-F12, and it reserves F12 for the menu: no command, no macro
and no recording uses it.  F10 and F11 have no command and are recorded and
played back by a macro.  The rows below name the keys of Strata; the column
Orig says what the original has on the key that does the same (F10 for F12),
and the column Strata says diff for such a key.

Terminal alternates.  Many terminals and window managers do not pass
Alt-F keys, Shift-Ins or Ctrl-Hyphen.  Strata therefore also has: Ctrl-F
(a menu of the Alt-F commands), Ctrl-F12 (the Marker menu), Alt-O
(Overtype) and Alt-I (italics, because Ctrl-I is Tab).

EQUATION MARKER: INSERT AND EDIT
================================

A. In the original (Manuscript 2.1, all steps tried under DOSBox-X)
------------------------------------------------------------------

Insert.
  1. Put the cursor where the equation goes.  This works in structured
     and unstructured documents (and in notes, comments and headers).
  2. Press Alt-F12.  The Marker Commands panel appears, three columns;
     Equation is in the first column after Endif.  Move to it and press
     Ins.  Shortcut: Ctrl-\ then e q opens the Equation panel at once.
  3. The Equation panel (title Equation) has the fields:
       Equation:          ...   Space opens the Equation Edit editor
       or File Name:            an equation read from a file
       Position:          Fixed (default), Floating or In Text
       Optional:  Width, Height, Scale (in inches / a factor)
       Name (for Table of Figures):
       Print/Preview:     No (default), Print or Preview
     Up and Down move between the fields; Return accepts a field and
     moves on; Space opens a list or a box; Ins accepts the panel.
  4. Space at Equation: opens Equation Edit, a full editor whose status
     line says EQUATION EDIT and whose bottom line says 'Press Ins to
     Save Changes or Esc to Restore Previous Version'.  Type the text
     of the equation, for example:   a sub 1 over b super 2
     Ins saves and returns to the panel, where the field shows the text
     followed by '...'.  Blocks and columns can be added, but only the
     first column of the first block is the equation; the others are
     comments that do not print.
  5. Ins on the panel puts the marker in the text.

The panel's checks (messages seen):
  'Width, Height and Scale cannot be used with Position: In Text'
  'Not a valid marker (Scale cannot be used with Height or Width)'
  'No equation was specified for the Equation marker.'  (help text)
Print/Preview is an action, not a setting: Preview ran at once and
stopped with 'Error: Unable to Preview document; invalid graphics
display driver' (no graphics driver under DOSBox-X); it is not stored.

Seen in the text.  The marker is drawn as   [EQN "a sub 1 over b super
2"]   (the default Short display mode, with the text in quotes).  When
the cursor is on it the status line says  Attr: Equation  (an empty
marker shows as [EQN ] in the Short mode and [EQUATION ] in the Long
mode; see GLOBAL-MENU.txt).

Edit.  Put the cursor on the marker and press Alt-F12 (or Ctrl-\ e q):
the Equation panel opens at once with the saved values (tried); Space at
Equation: opens the editor again.  Esc leaves the panel unchanged.  The
Search and Replace commands also look inside equations (help).

The language.  The text is the original's equation language, not TeX:
words separated by spaces, with keywords: sub, super, over, below, above,
left, right, center, stack, matrix, end, sum, int, product, root, Greek
letters by name, #R #F #I #B #C #S (fonts), #0 to #4 (spaces), (| |) and
#[ #] (groups).  The help topics 'Equation Keywords'
(about nine pages) list them all.

B. On disk (bytes written by the original)
-------------------------------------------

Saved from the original with Position Fixed, Width 3, Height 1, Name
'Eq one' (the CR LF line ends are written out; the marker is inside the
T record of the block, it is not a record of its own):

    ... text ^S 9 ( S CR LF
    T a sub 1 over b super 2 1D 00 CR LF      the nested text record
    2 3000 CR LF                              field 2: width, 3.000 in
    3 1000 CR LF                              field 3: height
    6 Eq one 00 CR LF                         field 6: name, a text
    ^S ) 1D 00 CR LF                          end of the marker

(^S is byte 13 hex.)  The records after the nested text are the fields
of the panel, in the order of their numbers; a field that has its default
is left out.  Found by changing one setting at a time:

  field  meaning                    value
  1      file name (or File Name)   text ending in NUL; then there is no
                                    nested S/T text  (1ESRC.DOC 00)
  2      width                      thousandths of an inch: 3000
  3      height                     thousandths: 1000
  4      scale                      thousandths: 2.000 is 2000
  5      position                   1 Floating, 2 In Text; Fixed = no
                                    record
  6      name for Table of Figures  text ending in NUL

Print/Preview is not stored.  Scale and Height or Width cannot both be
set, and none of the three can be set with Position In Text.
DOC-FORMAT.txt lists only 'nested text; 5: position' for type 9; fields
1 to 4 and 6 and the position values are new here and should be added
there.  Not yet checked: what the original does with a missing file for
field 1, and the value of Position when the panel's default is changed
back to Fixed (assumed: the record is removed).

C. In Strata today
-----------------

Insert: Alt-F12 (or Ctrl-F12, or Ctrl-F then Marker) opens the Marker
Commands menu; choose Equation.  There is no Ctrl-\ accelerator.
Strata opens a text editor of its own first (status EQUATION EDIT, the
same kind of mini editor as the original's Equation Edit; Ins saves,
Esc restores), and then inserts the marker.  There is no panel after
it: Strata's marker table has no fields for type 9, so Position, Width,
Height, Scale, File Name, the name for the Table of Figures and
Print/Preview cannot be set.
Edit: cursor on the marker, Alt-F12 opens the same text editor on the
saved text.  The payload reader keeps records it has no field for, so the
field records (1 to 6 above) of a marker that came from the original
should survive an edit and a save; this was not tried here.
Display: the marker is drawn as [EQN text] in the Short mode, the text
without quotes, as plain text from the nested block when it has one line;
the display modes of GLOBAL-MENU.txt apply (diamond, name, short, long,
hidden).  The equation is not typeset, evaluated or printed;
the text export and the preview show the label.

Gaps against the original:
  - No Ctrl-\ e q accelerator (and none of the other Ctrl-\ ones).
  - No Equation panel: Position, Width, Height, Scale, File Name, Name,
    Print/Preview, and the checks that go with them.
  - The label has no quotes around the text.
  - Space/Ins inside the panel work differently because there is no
    panel; Return in the editor inserts a new line of the equation.
  - Nothing reads the original's language; the TeX plan is in
    EQUATIONS.txt (a new equation would carry a marker flag, the position
    and size fields above would still apply to it).

EQUATION EDITOR, CTRL-W (added after the report above)
------------------------------------------------------
Ctrl-W in the equation editor (Alt-F12 on an Equation marker; the status line
says EQUATION EDIT) shows an enlarged picture of the equation as it is now,
or the message that latex gave when it could not typeset it.  Esc goes back
to the editor.  It needs the X11 version, latex and dvipng.  Strata only; the
original has no such key.


Function key labels of the modifier keys
----------------------------------------

With Display On-Screen Help? set to Yes (the default; Global, Options), the
two bottom lines of the edit screen show the labels of ten keys.  In the
original, which has F1 to F10, they change while a modifier key is held (seen
in DOSBox-X):

  none   F1 Help, F2 Split, F3 Copy, F4 Cut, F5 Paste, F6 Format, F7 Move,
         F8 Table, F9 Search, F10 Menu
  Shift  empty labels (Shift has no function key commands)
  Ctrl   F1 Learn, F2 Math, F3 Lib Copy, F4 Lib Cut, F5 Lib Paste, F6 Case;
         F7 to F10 empty
  Alt    F1 Compose, F2 Append, F3 Join, F4 Delete, F5 Overtype,
         F6 Set Attr, F7 Go To, F8 Border, F9 Replace, F10 Marker

Held together, Alt wins over Ctrl and Ctrl over Shift (Shift+Ctrl shows the
Ctrl labels, Ctrl+Alt and Shift+Ctrl+Alt the Alt labels).  The labels go back
when the key is released.  Strata does this in the X11 version; a terminal
cannot see a modifier key alone, so it always shows the usual labels.  The
columns of the labels are 0, 15, 32, 51 and 66 (F9) or 65 (the last key).
In Strata the last key of the second row is F12 and not F10: F12 Menu, with
Ctrl and with Alt F12 Marker.  F10 and F11 have no command and no label.

Moving a section left or right (Alt-[ and Alt-]; Alt-< and Alt-> also work,
and are the only ones in a terminal, where Alt-[ cannot be told from the
start of a key sequence).  Right makes the section the last subsection of
the section before it; its own subsections go with it.  Left makes it a peer
of its parent, placed after it, and the sections that followed it become its
subsections: with 2, 2.1, 2.2 and 2.3, moving 2.1 left gives 3 with 3.1 and
3.2 (the old 2.2 and 2.3).  Any section can move, not only the last one.

The collapsed or expanded state of the sections is saved in the file, and
changing it counts as a change of the document: Quit asks to save it (seen
in the original).
