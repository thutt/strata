WHAT "CHECKED" MEANS HERE

  Two kinds of check were made, and the ledger says which one a section had.

  M  Mechanical, for every section: the program is the truth and a tool
     compares it with the text (checkfacts.py F1 to F6, checkeditorial.py
     E1 to E22, checkspell.py, checkkeys, checknames, checkimpl, check-style,
     check-edition, check-numbers, check-pictable).  Every section has M.
  R  Read line by line against the program.  Only the sections that the
     column read marks yes were read this way.  The rest of the manual was
     NOT read line by line in this run; that part of the task is open (see
     OPEN at the end).

  The column changed says that a line of the section was changed in this
  pass (the text, not only a heading).

  Sections of the single document: 1100.  Read line by line: 27 (the
  sections of the first part of the Print chapter, down to the messages
  of a print, and section 1.1).
  Changed in this pass: 43.  Checked mechanically only: 1073.

THE CHECKS THAT THE PASS ADDED (all run by build.sh check-style)

  F1  Every message of the Editor (ed_msg, popup_msg) is in the manual.
  F2  Every menu entry that the Editor prints with --dump-menus is named as
      menu, entry (Print, Preview).
  F3  Every option that a program reads from its command line is in the
      manual (13 of the Printer and Editor options were missing).
  F4  Every marker type has its section.
  F5  Every label of a field is in the manual.
  F6  Every sample named in the manual is in the samples.
  E19 The words See also are not used; E20 and E21 the patterns of a marker
      entry and of a File command; E22 no word before a reference.
  S   Spelling of the running text with aspell (it found 15 times centerd).
  And the generator writes the index entries of the second names of things
  (manual/src/synonyms.txt): Dialog, See Panel.
