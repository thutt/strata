Audit of the tests of tasks 22 to 25 for vacuous checks
========================================================

A check is vacuous when it passes although the feature does nothing.  The
method is mutation testing: one line of the program is changed so that the
feature is lost (and the program still builds with -Werror), the test is run,
and the program is restored.  A good check must fail.  The program was
restored after every run; no mutation was committed.

Tests and what they are made of
-------------------------------

tests/printcolor.py   Print in Black and White: LaTeX text, pixels of page 1.
tests/headfoot.py     Headers and footers: made documents, pdftotext by page.
tests/indexlist.py    Index and lists: made documents, pdftotext by page.
tests/pagenumlevel.py Page Number Level: made documents, pdftotext.
tests/printfield.py   Print field, Joined headlines, borders: made documents.
tests/levelindent.py  Indent to Next Level and Ruler: x positions in points.
tests/winding.py      Winding Columns: LaTeX text and word positions.
tests/calctest.c      The calculator: 50 expressions with exact results.
tests/bordertest.c    The border masks: exact values.
tests/smoke.py        The blocks Case, Math, Global (headers, Winding), Border,
                      Initial Macro Set and Library, backups, Include.

All of the scripts above except smoke.py build their own documents in a
temporary directory, so the input never holds the expected result.  smoke.py
mostly copies sample/cns10pp.doc; that is where the Border checks were vacuous
(fixed in commit ed362854).

Vacuous checks found and fixed
------------------------------

indexlist.py, the lists.  The check of the list of figures only looked for the
names of the figures, and the check of the list of tables only for the names of
the tables.  A list that held every kind passed.  Two checks were added: the
list of figures holds no table name, the list of tables holds no figure name.
The check of the index of an Include marker had the form A or (B and C); it
now requires both entries.

calctest.c, the rounding.  No expression had a cut-off digit of exactly 5, so
half-down rounding passed.  Two checks were added: 100 nines plus 0.5 rounds up
to 1E+100 and 100 nines plus 0.4 rounds down to 100 nines.

bordertest.c, the text of the record.  The flag written by border_format and
the limit of a mask to eight bits were not tested.  Three checks were added.

smoke.py, the Odd Page Layout panel.  The check named "in brackets" looked only
for the words Odd Page Layout and Header.  It now sets the Global Header first
and asserts Header: [Chapter | \page\ | Strata], and asserts before that the
text is not there.

smoke.py, Math.  Two negative checks held although the calculator did nothing:
the clipboard after a division by zero (nothing was put there either way) and
Undo after a calculation (Undo took back the typing either way).  Both now
first assert the message of the calculation: "Cannot divide by zero" in the
first, "Result: 4" in the second.
