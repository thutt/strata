
------------------------------------- Join -------------------------------------

Join (Alt F3) joins the current column, block, or section to the following one 
and retains the format settings of the current column, block, or section.

Join the current column     Join the current block     Join the current section
with the column to the      with the following         with the following
right.                      block.                     section.
         +--------------+                |                 +----+
            +----------------------------------------------------------+
            |        Column            Block            Section        |
            +----------------------------------------------------------+
--Procedure---------------------------------------------------------------------

 Press Join.
 Select Column, Block, or Section and press Enter.
