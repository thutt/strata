
--------------------------- Window Zoom-up/Zoom-down ---------------------------

Use Menu (F10) Edit Window Zoom-up to temporarily display only the current 
window; Window Zoom-down displays both windows.           Accelerator:   Ctrl Z

Window Zoom-up temporarily hides the second window from view. Use Window Close 
to close a window.
