
-------------------------------- Print Document --------------------------------

Copies:            Enter the number of copies you want to print (up to 999).
          
Print Quality:     Select Final to use the fonts you specified and the highest
                   density graphics. Select Quick Print to print more quickly,
                   using lower quality fonts and lower density graphics.

Double Sided?      Select No to print the document on only one side of the 
                   paper; select Yes to print on both sides of the paper. (You
                   will be prompted if it is necessary to reinsert the paper.)

Sort Output Pages? Select No to print the document in the following order:
                   title page, document body, index, table of contents/
                   figures/tables, error log, document print summary. Select
                   Yes to print the document in the following order: title
                   page, table of contents/figures/tables, document body,
                   index, error log, document print summary.  If your printer
                   stacks pages backward and you select Yes, the pages will be
                   sorted in the correct order rather than with the last page 
                   on top.
