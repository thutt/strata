
-------------------------- Datacopy Image File Import --------------------------

Datacopy Image File Import converts files created on a Datacopy digitizer into
bit map image files.

  +----------------------- Datacopy Image File Import -----------------------+
  |                                                                          |
  |              Working Directory:                                          |
  |                                                                          |
  |       Datacopy Image File Name:                                          |
  |                                                                          |
  |            Bit Image File Name:                                          |
  |                                                                          |
  +------------------------- Press Ins to Import File -----------------------+

# Enter the name of the Datacopy file to convert, including the full path name
  if the file is not in the current working directory.

# Enter a name for the converted bit mapped file, including a file name 
  extension of either BIT or RLE.

# Use the Picture marker to include the converted image file in a document.
