-------------------------------- Error Messages --------------------------------
-- Too many graphics images on a single line --

There are too many graphics images to display on a single line.  Delete some
images or split the images onto more than one line and retry the operation.

-- Too many winding column format changes on page -- 

Reduce the number of winding column layout changes for the current page.

-- Top and bottom margins overlap -- 

The top and bottom margins overlap.  Reenter the margins on the Global Page 
Layout panels and reprint the document.

-- Top margin is smaller than minimum required by printer --

The printer requires a larger top margin than was specified on the Global Page 
Layout panels. Edit the margin selections and reprint the document.

-- Truncated file (<description>: <filename>) --

The file you retrieved is damaged. Use a backup copy of the file.
