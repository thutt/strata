
-------------------------- HP ScanJet Image File Import ------------------------

HP ScanJet Image File Import converts TIFF files created using the HP ScanJet 
Scanning Gallery software to Manuscript graphics image files.

  +-------------------- HP ScanJet Image File Import (TIFF) --------------+
  |                                                                       |
  |             Working Directory:                                        |
  |                                                                       |
  |    HP ScanJet Image File Name:                                        |
  |                                                                       |
  |           Bit Image File Name:                                        |
  |                                                                       |
  +------------------------- Press Ins to Import File --------------------+

# Enter the name of the ScanJet file to convert, including the full path name 
  if the file is not in the current working directory.

# Enter a name for the converted bit mapped file, including a file name 
  extension of either .BIT or .RLE.

# Use the Picture marker to include the converted image file in a document.
