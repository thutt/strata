----------------------------- PC Paintbrush File Import ------------------------

PC Paintbrush File Import converts PC Paintbrush .PCX or .PCC compatible files 
to Manuscript graphics image files.

  +-------------------------- PC Paintbrush File Import ------------------+
  |                                                                       |
  |             Working Directory:                                        |
  |                                                                       |
  |       PC Paintbrush File Name:                                        |
  |                                                                       |
  |           Bit Image File Name:                                        |
  |                                                                       |
  +------------------------- Press Ins to Import File --------------------+

# Enter the name of the PC Paintbrush file to convert, including the full path
  name if the file is not in the current working directory.

# Enter a name for the converted bit mapped file, including a file name 
  extension of either .BIT or .RLE.

# Use the Picture marker to include the converted image file in a document.
