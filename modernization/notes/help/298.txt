
----------------------------- Create Separate Documents ------------------------


The table of contents, figures and tables, index, and notes that are 
automatically generated by Manuscript use a format that you can customize on 
the Page Layout panels or Note Format panels.  If you want to further change 
the structure or format of these pages, use the Create Separate Documents 
prompt on the final print Optional Settings panel.


--------------------------------------------------------------------------------


# Separate documents are created with the current document's name and the 
  file extension indicated in parentheses under the Create Separate Documents
  prompt (for example, .TOC for the table of contents or .IDX for the index).

# Once a separate document has been created, it no longer reflects changes
  made to the original document (for example, additional index entries).
