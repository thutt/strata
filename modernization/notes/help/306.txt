
------------------------------------- Named ------------------------------------

Use the Menu (F10) Global Named options to edit or delete master named block 
formats.

                 named block formats.        block formats.

You can use master named block format settings by entering a named block name 
at the Named Block Format prompt on the Current Block Format panel.
