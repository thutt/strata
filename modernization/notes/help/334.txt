-------------------------------- Retrieve Macro Set ----------------------------

Use Macro Retrieve to retrieve an existing macro set from disk into memory.  A 
macro set must be in memory before you can run any of the macros in that set.

---Procedure--------------------------------------------------------------------

 Press Menu (F10) and select Tools +---------- Retrieve Macro Set -----------+
  Macro Retrieve.                   |                                         |
                                    |Working Directory:                       |
 Enter the macro file name or press|  File Name:                             |
  Gray + and select from the list.  |    Options:v Overwrite Current Macros   |
                                    |              Merge with Current Macros  |
 Select whether the retrieved      |                                         |
  macros should overwrite the       +------- Press Ins to Retrieve File ------+
  current macros in memory or should 
  be added to the current macros. Use the Macro Save command before 
  overwriting if you want to save the current macros for future use.
--------------------------------------------------------------------------------
# The file name must use a .MAC extension; you do not need to specify a file
  name extension because the .MAC extension is assumed.  Be sure to change the 
  working directory or specify the full path name to retrieve the file from a 
  directory other than the current working directory.
