
---------------------------------- Comment Edit --------------------------------

Use the Comment Edit panel to enter the text of a comment.

--Procedure-----------------------------  +----------- Comment Edit -----------+
                                          |                                    |
 Move the cursor to the position at      |                                    |
  which you want a comment.               |                                    |
 Press Marker (Alt F10).                 |                                    |
 Select Comment.                         |                                    |
 Press Space Bar at the Comment prompt   |                                    |
  to display the Comment Edit panel.      |                                    |
 Enter the text and press Ins.           |    Press Ins to Save Changes or    |
 Type your initials, if desired.         +- Esc to Restore Previous Version --+
 Press Ins to accept the comment and 
  return to the editor.
--------------------------------------------------------------------------------
# You can add columns or blocks and set local text, column, and block formats
  in a comment.
# You have three options for printing comments: not at all, print the comment 
  and initials in brackets ([ ]) in the text, or print the initials in brackets
  ([ ]) in the text and print the comment at the end of the document.
