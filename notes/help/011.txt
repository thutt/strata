--------------------- Add Document to Spelling Dictionary ----------------------

Add Document to Spelling Dictionary adds entries from a document to a custom 
spelling dictionary.

  +------------------ Add Document to Spelling Dictionary -------------------+
  |                                                                          |
  |             Working Directory:                                           |
  |                                                                          |
  |                 Document Name:                                           |
  |                                                                          |
  |      Spelling Dictionary Name:                                           |
  |                                                                          |
  +---------------- Press Ins to Add Document to Dictionary -----------------+
--Procedure---------------------------------------------------------------------
 Create and save a document containing the words you want to add.  Enter all
  derivations of a word, such as plural, possessive, and capitalization (all
  lowercase words are added in lowercase and with an initial capital).
 Select Maintain Dictionaries from the Document Manager.
 Select Add Document to Spelling Dictionary.
 Enter the name of the document containing the dictionary entries to add and 
  the dictionary in which to add them.
