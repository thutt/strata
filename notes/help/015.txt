
------------------------ Import from 1-2-3/Symphony File -----------------------

Use Import from 1-2-3/Symphony File on the Document Manager to convert 1-2-3 
or Symphony files into Manuscript document files.  With this utility you can 
import an entire worksheet or just a range of data, and you can import any 
SHEET, DOC, or FORM window from a Symphony worksheet.

You can also import 1-2-3 or Symphony worksheets directly into a document using
the Worksheet marker.
