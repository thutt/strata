
---------------------------------- Index Marker --------------------------------
Use the Index marker to designate an index entry and page number. The index is
automatically generated by Manuscript.
                                   +-------------------- Index ----------------+
--Procedure----------------------  |                                           |
                                   |        Main Heading:                      |
 Move the cursor to the text you  |                                           |
  want indexed.                    |          Subheading:                      |
 Press Marker.                    |                                           |
 Select Index.                    |      Reference Text:                      |
 Complete the Index panel.        |                                           |
 Press Ins to enter the marker.   | Page Number/Reference Attributes:         |
                                   |                                           |
---------------------------------  +--- Press Ins to Use Displayed Settings ---+

# You can index a subject by main heading and subheading. To index a subject
  under several headings, create separate index entries for each heading.  
  More than two identical entries on sequential pages are treated as a range. 

# The global attributes for the page number or reference text are set on the 
  Index Style panel. The page layout of the Index is set on the Index Page 
  Layout panel.
