Grouping Symbols
--------------------------------------------------------------------------------
                         Name                   Keyword
--------------------------------------------------------------------------------
                         Parenthesis            ( )
                         Bracket                #[ #] 
                         Brace                  { }
                         Vertical               (| |) or (^ ^)
                         Double Vertical        (|| ||) or (^^ ^^)
                         Floor                  (_ _)
                         Ceiling                (/ /)
                         Angle                  (< >)
                         Null                   #( #)
--------------------------------------------------------------------------------

              Example equation:  d - #[a + 3x#]    ->    d - [a + 3x]
