
---------------------------------- Cut to Library ------------------------------

Use Lib Cut (Ctrl F4) to cut a region of a document to a new library entry.

---Procedure--------------------------------------------------------------------

 Make sure that you are at the          +--------- Cut to Library --------+
  start or end of the area to cut.       |                                 |
                                         |  Entry name:                    |
 Press Lib Cut.                         |  Description:                   |
                                         |  Include in Library?            |
 Select the type of area to cut         |                                 |
  (text, column, block, or section)      +---- Press Ins to Create Entry --+
  and highlight the region to cut. 

 Enter a name for the entry and a description if desired.

 Set Include in Library to Yes to include the new entry in the current library.

 Press Ins to create the entry.
