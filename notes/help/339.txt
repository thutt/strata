
----------------------------------- Save Library -------------------------------

Use Library Save to permanently save a library to a file on disk.
          
---Procedure--------------------------------------------------------------------

 Press Menu (F10) and select Tools   +------------ Save Library -------------+
  Library Save.                       |                                       |
                                      |  Working Directory:                   |
 Enter the name of the library       |      File Name:                       |
  file.                               |    Description:                       |
                                      |         Author:                       |
 Enter a description and author      |       Revision:                       |
  name, if desired.                   |                                       |
                                      +-------- Press Ins to Save File -------+
 Press Ins to save the file.         

--------------------------------------------------------------------------------
# The file name must use a .LIB extension; you do not need to specify a file
  name extension because the .LIB extension is assumed.  Be sure to change the
  working directory or specify the full path name to save the file to a 
  directory other than the current working directory.
