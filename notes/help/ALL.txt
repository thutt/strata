#### TOPIC 1: Document Manager

------------------------------- Document Manager -------------------------------

The Document Manager is the first panel you see each time you run Manuscript 
from DOS.  The Document Manager displays the following document handling 
functions:

  Edit Document ................... Create and edit a document.
  Print Document .................. Print a formatted document.
  Preview Document ................ Preview a formatted document.
  Check Document Spelling ......... Spell check a document.
  Maintain Dictionaries ........... Create and edit custom dictionaries.
  Compare Document Versions ....... Compare versions of a document.
  Import from 1-2-3/Symphony File . Import worksheets from 1-2-3 and Symphony.
  File Conversion Utilities ....... Import and export files from other programs.
  Batch Print Utility ............. Create, edit, and run batch print files
  Maintain Download Fonts ......... Manage download fonts.
  Setup ........................... Configure the program to your needs.
  Quit ............................ Return to DOS.

Highlight the option you want by using the cursor-movement keys or pressing the
first letter of the option.  Press Enter to complete the selection.

         DOS Command Line           Keyboard Summary          Help Index

#### TOPIC 2: Selecting a File

------------------------------- Selecting a File -------------------------------

Before entering the editor you specify a document to create or edit.

--Procedure---------------------------------------------------------------------

   Enter the name of the file (and full path name if the file is not in the
    current working directory) and press Ins.
                   or
    Press Gray + at the Document Name prompt to list the available files in 
    the current directory, highlight the file you want to edit, and press Enter.

   Enter the new file name and press Ins to display the New File panel.  File
    names and extensions must conform to the DOS file name conventions.  If no
    file extension is specified, Manuscript uses the .DOC extension.

   Complete the New File panel and press Ins to begin editing the new file.

#### TOPIC 6: Preview

------------------------------------ Preview -----------------------------------

Preview displays a formatted document one page at a time.  The following are the
preview display modes.

# Content/Full-page toggles content and full-page display modes.  Content 
  displays the text of the document across the full width of the screen.  
  Full-page shows the current page of the document, selector box, magnifier 
  window, preview status, and message box.

# Greeking displays all or part of the text as dashed lines.

# Reverse/Normal toggles reverse and normal video modes.

# Errors displays a log of format errors for the current previewed page.
--------------------------------------------------------------------------------

To change the display mode, press Menu (F10) in preview and select the option
you want.  The menu also lists commands to go to another page, zoom a graphics
image, or quit preview.

#### TOPIC 8: Check Document Spelling Menu
-------------------------- Check Document Spelling Menu ------------------------

Accept: Accepts the word exactly as it appears and marks it in the rest of
        the document as correct, but does not enter it in a custom dictionary.

Define: Enters the word into a custom dictionary (if you are using one). If the 
        word is lowercase, Define enters the word in lowercase and initial cap-
        ital. If the word has an initial capital or is uppercase, Define enters
        it exactly as it is capitalized. If you have specified more than one 
        custom dictionary, you will be asked for the name of the dictionary.

Ignore: Accepts the word but continues to flag it as misspelled if it 
        appears in other locations in the document.

Edit:   Moves the cursor to the word so you can correct it. Press Ins to use 
        the corrected word. If Auto Correct is set to Yes, the edited 
        correction will automatically be made for all occurrences of the word.

Guess:  Displays words with similar spelling or sound. Select an alternative 
        or press Esc to return to the correction options.

Line:   Moves the cursor to the current line so you can edit it.  Press Ins to 
        use the corrected line.
--------------------------------------------------------------------------------
        Check Document Spelling       Keyboard Summary        Help Index

#### TOPIC 24: Printer Drivers
-------------------------------- Printer Drivers -------------------------------

The Primary Print Driver is the default printer for final printing; the 
Secondary Print Driver is the default printer for draft printing.  When you 
print, you can select either the primary or secondary printer.

The Port specifies the communications port through which Manuscript sends 
information to the printer.  Although most systems use the PRN port, some
printers, such as the Apple LaserWriter, may use the COM1 port. If you are using
Manuscript on a network, consult your network manager for the correct port.

--Procedure---------------------------------------------------------------------

 Move the cursor to the applicable prompt and press Space Bar.
 Highlight the appropriate selection for your hardware and press Enter.
 Many printers have a secondary panel of additional settings, such as page 
  orientation. In such cases, make your selections and press Ins.
 Press Ins to return to the Setup panel.
--------------------------------------------------------------------------------
# See the Hardware chapter in the Reference manual and print PDUPDATE.DOC for 
  more information about printer drivers, including specific printer configur-
  ations, available fonts, graphics resolution, special symbols, and notes.
# See your DOS manual for more information about communications ports.
--------------------------------------------------------------------------------
      Document Manager       Setup       Keyboard Summary       Help Index

#### TOPIC 25: Virtual Memory Setup

----------------------------- Virtual Memory Setup -----------------------------


Use the Virtual Memory prompt on the Setup panel to configure virtual memory.
Manuscript uses your system's available memory and storage devices as virtual 
memory so you can work with large documents; virtual memory is initially 
configured to use up to 1 Mb of free space either on an EMS board or your hard 
disk.  This configuration can efficiently handle documents of up to 
approximately 100 pages.


# Select Standard if you plan to create a document less than 100 pages.

# Select Custom if you plan to create a document larger than 100 pages, if you
  do not have enough space available on an EMS board or your hard disk to 
  create your documents, or if the error message "Out of Virtual Memory" is 
  displayed.

--------------------------------------------------------------------------------

Press Ctrl M while in the editor to display the Virtual Memory Status panel.

#### TOPIC 196: Unstructured and Structured Documents

--------------------- Unstructured and Structured Documents --------------------

To accommodate a wide range of documents, you can have unstructured or
structured documents.

Unstructured: An unstructured document is created in unstructured edit and
              has one or more text blocks or columns; it does not have 
              sections, levels, or headline blocks. 

              Use unstructured edit to create simple documents such as memos,
              letters, or notes.

Structured:   A structured document also has one or more blocks or columns, 
              but they are organized into sections and levels. The first 
              block of each section is a headline block, which is used as 
              a section title, in the table of contents, and when collapsing 
              sections to outline or reorganize a document.

              Use structured edit to create more complex documents, such as
              technical papers, or for any document that needs sophisticated 
              formatting.

#### TOPIC 203: Ruler Spacing

--------------------------------- Ruler Spacing --------------------------------

Ruler spacing settings made on the local format (F6) and global format (F10 
Global Format) panels control the size of a ruler unit when the document 
final prints. Ruler units affect the following settings: column widths, tab 
placement, left and right block indents, and level indents.

Ruler units represent either a relative distance or an absolute measurement 
from a margin.  The Ruler prompt has the following options:

Relative: Text, blocks, and columns have the same relative position in the print
          area that they have on the screen. For example, if you place a tab at
          position 40, text aligned with the tab prints halfway between the left
          and right margins of the paper (40 divided by 80 equals 1/2).

10/inch:  With any of these absolute ruler settings, each space on the ruler 
12/inch   represents a fraction of an inch. Use absolute spacing to position 
15/inch   a column a precise distance in inches from the left margin.  For
          example, if you set ruler spacing to 10/inch (10 units per inch)
          and the tabs are at 10 and 25, the tabbed text prints 1 inch and 
          2.5 inches from the left margin.

#### TOPIC 208: Import Worksheet Formats

--------------------------- Import Worksheet Formats ---------------------------

You can import a 1-2-3 or Symphony worksheet in one of five different formats:

Table:    Imports each row into a block and each cell into a fixed-width 
          column. Text longer than the column width wraps in the column.

Column:   Imports each row into a block and each cell into a fixed-width 
          column. Text longer than the column width extends until the next 
          cell containing data is encountered.

Tab:      Imports each row into a block using tabs to separate cells. Text
          longer than the column width extends to the next cell containing data.

Document: Imports each row that has data in only the left-most cell into a 
          block. Each margin or tab change in the worksheet starts a new block 
          in the document. All text wraps until an end-of-line character is 
          encountered. Rows with data in cells other than the left-most cell 
          are imported using Table format.

Document: Same as Document format except that an end-of-line character is 
Image     inserted at the end of each line.

#### TOPIC 229: Markers

------------------------------------ Markers -----------------------------------
The following markers are used in a merge text document.

Merge: Inserts the name of a merge variable. When the document is printed, 
       the value of that variable, as specified in the merge data document,
       is inserted at the location of the Merge marker.

If:    Inserts a conditional If statement in a merge text document. The If 
       expression compares a variable in a merge data document to a numeric 
       or string expression. The text following the If marker up to the Endif
       marker prints only when the If condition is true. The If statement must
       begin with a merge variable name, followed by an operator, and end with
       a numeric or string value. Valid operators are =, <>, >, <, >=, or <=.

Else:  Inserts a conditional Else statement that relates to the preceding If
       statement.  Else marks the start of alternative text to print when the 
       If statement is false.

Endif: Ends a conditional If statement.  Each If marker must be paired with an
       Endif marker.

For more information on merge, see chapter 4 in the Reference manual.

#### TOPIC 250: Avoiding Virtual Memory Errors

------------------------ Avoiding Virtual Memory Errors ------------------------


# To help prevent virtual memory errors, keep your hard disk clean of old files.


# Make sure you end each session by choosing Quit from the Document Manager. 
  Be especially careful not to reboot your system after having gone to the
  DOS prompt using the DOS command from within Manuscript; Manuscript is still
  active in memory during this time.

  Turning off the computer, rebooting before quitting Manuscript from the
  Document Manager, or encountering an untimely power failure can prevent 
  temporary files from being closed and may lose clusters of data. Lost clusters

#### TOPIC 253: Indents and Margins

------------------------------ Indents and Margins -----------------------------

Indent settings indent levels, blocks, or text from the page margins.  Margin 
settings specify the distance from the edge of the paper to the start of text.

There are five type of indents in Manuscript:

# Level indents indent sections at a specific level from the sections at the 
  preceding level.  For example, if Indent per Level is set to 3, level 2 
  sections are indented 3 ruler units from level 1 sections.
# Block indents indent the text in the block left and/or right.
# Line indents indent lines of text within blocks or columns.
# Hanging indents set block format settings so the first line of the block 
  "hangs" to the left and subsequent text is indented.
# Text indents indent lines of text in a block, but do not set block format 
  settings.
  
Indents are cummulative. For example, if a document has level indents set to 3 
and a block in a level 2 section has a left block indent of 5, that block is
indented 8 ruler units from the left page margin.  (You can use either negative
or positive numbers for indents.)

------------ Creating Custom Spelling and Hyphenation Dictionaries -------------

To create a spelling or hyphenation dictionary, just create a new document and 
enter words following these rules:

# Words must be separated by either a space, a tab, or an end-of-line character.

# For spelling dictionaries, use capitalization and punctuation only if a word
  must appear that way. Words entered in lowercase are also added with an

Document Spelling panel; Manuscript creates it as you spell check a document.

#### TOPIC 297: Section Tag

#### TOPIC 349: Font Load Modes

------------------------------- Font Load Modes --------------------------------
Use the Specify Font Load Modes option from the Maintain Download Fonts menu to
display a panel for each of the typefaces in the font directory. These panels 
display the font name, point size (for HP printers), attribute, character set, 
and load mode. You can change the load mode on these panels by pressing Space 
Bar, selecting a load mode option, and pressing Ins. The load mode options are:

Unassigned:  These fonts are not downloaded and are unavailable in Manuscript.
             Use this mode to exclude specific fonts in your font directory
             from Manuscript's Typeface List.

Pre-Load:    These fonts must be either already resident in the printer or 
             downloaded by using the Load "Pre-Load" Fonts menu option on
             the Maintain Download Fonts menu.

First Print: Each of these fonts is downloaded the first time you print a 
             document that has that font in the Typeface List. The font stays 
             resident in the printer after the document is printed.

Every Print: Each of these fonts is downloaded each time you print a document 
             that has that font in the Typeface List; however, the font does 
             not stay resident in the printer.

#### TOPIC 364: Macros

------------------------------------ Macros ------------------------------------

Macros record a series of keystrokes that you can play back at any time. Macros
are named by a single alphabetic character and you use the Alt key with that 
character to play back the macro.  For example, you can define a macro that
searches for the occurrence of a word and then enters an Index marker, thereby 
creating an index entry for the word.


# Learn (Ctrl F1) saves keystrokes as you type.  Press Learn again to stop
  saving keystrokes.


Macros are stored temporarily in memory and must be in memory to run.  Macros 
are erased from memory when you quit Manuscript unless you have saved them to 
disk in a macro set.

Use the Menu (F10) Tools Macro Save command to save a set of macros permanently
to disk, or use the Menu Tools Macro Retrieve command to retrieve a set of 
macros from disk into memory.  Use the Menu Tools Macro Edit command to edit 
existing macro entries.

#### TOPIC 372: Block and Column Conceptual Overview
---------------------- Block and Column Conceptual Overview --------------------

Blocks are the foundation of a Manuscript document.  Blocks are units of text 
such as a single paragraph, an item in a list, a row in a table, or a headline 
in an outline.  You append (add) a new block in a Manuscript document each time
you create or add one of these items.

When you create a document, the first block is already on the screen.  When you
use Append (Alt F2) to add the second block, it is separated from the current 
block by a single horizontal line.  (The block indicator is for display purposes
only; it does not print.)

From blocks, you create all the other elements in a Manuscript document: 
columns, sections, and levels.

Every block has at least one column and can be split into more than one column.
For example, to create a table you split a block into as many columns as you
need.  Then append additional blocks with the same number of columns.  When you
are finished building the table, you can append a block without the columns.

You can also use Table (F8) to split blocks into columns and to size columns.
Columns are separated by vertical lines of dots on the edit screen.
--------------------------------------------------------------------------------
   Section and Level Overview         Append         Columns and Table Editor
                Keyboard Summary                   Help Index

#### TOPIC 373: Section and Level Conceptual Overview

----------------------- Section and Level Conceptual Overview ------------------

A section is made up of a group of related blocks.  Each section begins with a
headline block that contains the title or main topic for the section.  You can
add as many blocks or text as you need to the section.  The section can also
contain subsections, which have their own headline and text blocks.

Each section has a level that determines its relationship to the other sections
in the document.  Main topics are generally level 1 sections.  A subsection of 
a level 1 section is a level 2 section, a subsection of a level 2 section is a
level 3 section, and so on.

# You use Append (Alt F2) to add sections and subsections.  Sections are 
  separated by double horizontal lines on the edit screen.

# When you work with sections you are working in a structured document.

# You can collapse and expand sections so that you see just the section
  headlines, section headlines of certain levels, or section headlines and
  text of certain levels.  By using collapse and expand, you can quickly view
  an outline of a document and check its organization.
--------------------------------------------------------------------------------

    Collapse/Expand Keys          Keyboard Summary            Help Index
